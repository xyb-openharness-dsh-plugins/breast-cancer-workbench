## 本轮修正依据

- 全仓检索：`淋巴`/`水肿`/`臂围`/`内分泌`/`骨密度`/`LVEF`/`放疗` 在 v0.1 与文档中均为 0 次，确认是内容缺口而非表述问题。
- 参考实现 `xyb-workbench@0.1.27` `lib/client.js:104-110` 使用 `perspective + rotateY + backface-visibility`；v0.1 的 `metric-toggle` 是把卡片插到按钮下方，结构上不可能翻转。
- 一图秀缺 10 项能力（多序列、时间窗、缩放、治疗叠加、关键点、变化标注、点详情、分组、空态、免责），不是样式问题。
- 移动端自测方法有漏洞：上一版只抽查部分页面就写"无横向溢出"，实际"上肢与淋巴水肿"页 `scrollWidth=476`。改为**逐页测** `documentElement.scrollWidth`，34 页全部 = 390 才算通过。这条同样适用于后续验收：**抽查不算验证**。
