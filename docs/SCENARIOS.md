# 全病程场景候选 v0.2

共同方向已确认；以下任务细化由设计者提出，尚未真实访谈或通过产品验收。v0.2 依 GAP-ANALYSIS 补齐乳腺癌专属场景（S8/S9），并给每个场景标注落点字段。

| ID | 触发/主体 | 最少输入与步骤 | 产出及继续方式 | 落点（模块/字段） | 恢复/隐私 |
| --- | --- | --- | --- | --- | --- |
| S1 | 新确诊患者或代办者，不知道先做什么 | 可仅描述困惑 → 选择先理解 / 先理材料 / 先处理感受 → 查看解释与一件可选沟通准备 | 可保留问题或暂停，之后继续同一任务 | 看板；Question | 无资料可开始；不强制问卷或推断心理诊断 |
| S2 | 报告与治疗混杂，准备初诊/跨院/复诊 | 批量交材料 → 系统草稿与来源 → 用户选择少量核对/跳过 → 选入问题 → 预览摘要 | 可回源病情摘要和问题清单，多页同源复用 | 病情整理；Document/Candidate/Record | 解析失败保留原件；草稿不冒充已接受档案 |
| S3 | 治疗期间需要日常帮助 | 仅记一项不适/进食/担忧或直接提问 → 选择关联记录 → 查看帮助 → 保留问题 | 日常记录累积到下次就诊准备 | 营养/心理/不适记录；CareEntry | 代记标操作者；计划与实际分开 |
| S4 | 手术/放疗后，关注恢复和长期生活 | 选择眼前困难（伤口/肩臂/皮肤/体力）→ 查看自己已有建议 → 可选记录变化 → 准备专业咨询问题 | 康复或生活问题的持续回顾 | 全程与康复；术后恢复/长期生活 | 不自动给运动剂量；私密话题单独选分享 |
| S5 | 长期治疗/随访中的复查与担忧 | 录入已有安排 → 回顾近期变化 → 更新问题 → 复诊后补专业回复 | 下一次安排与可复用资料 | 一图秀/近期安排；Task/Question | 不自动生成统一复查方案；暂停记录不扣分 |
| S6 | 专业团队提出进一步评估/研究线索 | 选择治疗史与报告 → 检索有时效信息的条目 → 查看条件与未知项 → 收藏/形成核实问题 | 条目、来源日期、待核实条件和讨论材料 | 临床；TrialSnapshot/Question | 不输出入组结论；数据失效明确标记 |
| S7 | 照护者也需要帮助 | 选择代办患者任务或记录自己的困难 → 少量输入 → 选择保留/分享 | 自己的支持记录及患者代办结果分开 | 心理支持；CareEntry.ownerRole | 不把家属焦虑写成患者症状；跨账号协作未定 |
| **S8** | **患侧手臂发沉/袖口变紧，或术后想确认恢复进度** | **首次：选部位 → 按四点位记录健患侧周径（可只记 1 个点位）→ 系统算最大差值 → 看趋势与参考线 → 生成"值得向团队报告"的问题；复测：只填变化点位** | **臂围差序列进一图秀；问题进复诊准备；症状与功能影响另存** | **全程与康复 / 上肢与淋巴水肿；Measurement(arm_diff)、CareEntry(le_symptom)、Question** | **单次不判分期；不推荐压力等级或手法；方法变更即断线；不把围度写进公开分享默认项** |
| **S9** | **内分泌治疗期间关节痛、潮热、睡眠受影响** | **选症状与强度 → 记部位/时间 → 看与用药时间的对照 → 生成想问的问题（是否与药相关/如何缓解/是否需要评估）** | **症状轨道与问题清单；不评价是否继续用药** | **全程与康复 / 不适记录；心理支持；CareEntry(ai_joint/hot_flash)、Question** | **不做因果归因；不建议停药或补充剂；症状强度不做"评分"展示** |
| S10 | 术后带管回家，担心伤口与引流量 | 记当日引流量与伤口外观 → 对照出院医嘱 → 出现约定情况时提示联系团队 | 短期记录，拔管后归档 | 术后恢复；Measurement(drain_vol) | 不判断感染；不给换药步骤 |

首批原型走查建议：S2（资料闭环）、S8（上肢与淋巴水肿）、S5（时间轴回顾）。S1/S3/S4/S9 作为补充路径；S6/S7/S10 保留架构位置，一期不加深。

**S4 与 S8 的关系**：S4 是"术后整体恢复"的宽入口，S8 是其中一个高频、可测量、可长期追踪的窄任务。二者共用全程与康复模块，但 S8 有独立数据合同（四点位测量），不能退化成一张提示卡。
