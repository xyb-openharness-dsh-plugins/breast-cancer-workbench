# 乳腺癌领域模型与指标字典 v0.2

日期：2026-10-17。状态：设计建议，供 SPEC/SCHEMA/原型共用；**医学口径未完成中国指南核验**，凡涉及阈值、风险与处置的表述均标注为待核验，不写入产品结论。

v0.2 按用户 2026-10-17 决定修订：康复指标显示名改"上肢"（D15）；新增 §5.1「看法=信息」的落地方式（D16）。

本文件解决 GAP-ANALYSIS 中的两个高优先级缺口：领域维度缺失、指标字典缺失。

## 1. 为什么乳腺癌需要独立模型

同为"全病程工作台"，乳腺癌有三组别人没有的长期变量，直接决定记录结构与一图秀轨道：

1. **腋窝处理方式**（前哨活检 / 清扫 / 未处理）叠加**放疗野**（胸壁 / 锁骨上 / 腋窝），共同决定淋巴水肿风险。它不是"术后并发症"一个标签，而是终身随访变量。
2. **内分泌治疗以年计**（他莫昔芬 5–10 年、AI 5 年 + 骨健康管理），副作用是"日常体验"而非"治疗事件"，需要症状轨迹而不是疗程表。
3. **治疗相关器官毒性有明确随访指标**：蒽环类/曲妥珠 → LVEF；AI → 骨密度；化疗 → 血象与肝功。这些指标只有在"治疗暴露"背景下才有意义，必须与治疗事件同轴显示。

因此：治疗事件不是背景装饰，指标也不是孤立曲线。一图秀的本质是**暴露（治疗）× 结果（指标/症状）的同轴回顾**。

## 2. 维度枚举（候选，需专业确认）

| 维度 | 取值（候选） | 用途 | 注意 |
| --- | --- | --- | --- |
| 侧别 | 左 / 右 / 双侧 | 所有患肢记录、影像、病理 | 不与"优势手"混用 |
| 术式 | 保乳 / 全乳切除 / 改良根治 / 重建（即刻/延期） | 术后康复任务、身体形象话题 | 重建方式单独字段 |

| 全身治疗 | 化疗方案与周期、抗 HER2、内分泌（他莫昔芬/AI/卵巢抑制）、CDK4/6、PARP | 毒性随访、指标解读背景 | 计划与实际分开 |

| 骨健康 | DXA T 值、部位、日期、是否在 AI 治疗中 | 指标轨道 | 不与"骨折风险评分"混同 |

### 3.6 康复测量（本轮新增，核心）

| code | 名称 | 单位 | 形态 | 采集规则 | 可比性 |
| --- | --- | --- | --- | --- | --- |
| arm_diff | 患健侧臂围差（最大值） | cm | 折线 + 参考线 | 同一测量体位、同一四点位、同一天健患侧成对测量 | 仅同方法可比；换点位方案需新序列 |
| arm_vol_diff | 患健侧体积差 | % | 折线 | 体积法/BIS 结果，需记录设备与方法 | 不与臂围差互相换算 |
| arm_flex | 患侧上肢前屈 | ° | 折线 | 肩关节主动前屈，注明是否辅助 | 测量者不同需标注 |
| arm_abd | 患侧上肢外展 | ° | 折线 | 同上 | 同上 |
| grip | 患侧握力 | kg | 折线 | 同一握力计 | 同上 |
| drain_vol | 引流量 | mL/日 | 柱状 | 术后短期，按日 | 仅住院/带管期 |

> **命名约定（D15）**：模块名、话题标题、指标显示名统一用「术后上肢 / 上肢」，不用「肩」作主题名。`arm_flex` / `arm_abd` 量的是肩关节活动度，说明里可以写"肩关节前屈"，标题写"患侧上肢前屈"。数据库字段与页面文案不必同名，但**显示名不得出现"肩"作为模块名**。

臂围四点位（候选，需康复科确认）：腕横纹、前臂中段、肘横纹上 10cm、腋窝顶下 10cm。左右同点位成对测量，取差值最大值。

**参考关注线**：文献与临床常用"患健侧周径差 ≥2cm 或体积差 ≥10%"作为进一步评估的提示。本产品只把它画成一条虚线并标注"参考关注线，需专业确认"，**不据此判定分期、不输出诊断、不自动建议治疗**。该阈值的中国临床口径与测量规范仍待核验。

### 3.7 症状与体验（非数值，进一图秀为"标记轨道"）

| code | 名称 | 采集 | 显示 |
| --- | --- | --- | --- |
| le_symptom | 上肢沉重/紧绷/肿胀 | 0–3 × 4 项 | 一图秀下方色块轨道，不画成曲线 |
| ai_joint | 关节痛/僵硬 | 0–3 + 部位 | 同上 |
| hot_flash | 潮热/盗汗 | 频次/影响 | 同上 |
| fatigue | 疲乏 | 0–3 | 同上 |
| skin_rxn | 放疗区皮肤反应 | 0–3 + 描述 | 同上 |

> 症状不进折线图。0–3 量表是体验强度，不是检验值；画成曲线会制造"客观测量"的错觉。

## 4. 显示规则（硬约束）

1. **不同量纲不共轴**：多指标同图时，每条线按自身范围归一化，图例必须写"按各指标自身范围绘制，不代表数值可比"。
2. **单点不连线**：只有 1 次记录时只显示点与数值。
3. **断点优先于插值**：方法/单位/点位变更时断开曲线并在断点标注原因，不用虚线糊过去。
4. **未知四态分开**：未检测 / 未录入 / 待出结果 / 阴性，四者视觉不同。
5. **治疗带只做背景**：治疗区间用半透明色带，不压住数据点；不写因果箭头。
6. **不做风险评分**：不输出"复发风险""水肿风险百分比"等未经验证的合成分数。

## 5. 内容安全边界（本癌种特有）

| 话题 | 可以做什么 | 不可以做什么 |
| --- | --- | --- |
| 淋巴水肿 | 记录围度/症状、提示"值得向团队报告"、提供已存专业建议 | 判定分期、推荐压力等级、给手法引流步骤、承诺"练了就不会肿" |
| 术后上肢 | 记录活动度与肿胀、提示按出院医嘱执行 | 给具体动作/组数/负荷处方；把话题写成"肩关节康复" |
| 内分泌治疗 | 记录关节痛/潮热、整理提问 | 建议停药、换药、加用补充剂 |
| 骨健康 | 展示 T 值、提示与医生讨论 | 给钙/维D 剂量 |
| 生育 | 提供提问清单与转介提示 | 给"能否怀孕"结论、按年龄推断 |
| 复发担忧 | 允许表达、整理问题、**把担忧存成一条"看法"** | 用标志物曲线安抚或预警；把看法写成"疑似复发" |

### 5.1 "看法=信息"怎么落（D16）

用户的判断、担心、猜测（"我是不是复发了""我觉得是放疗造成的"）**是数据，不是结论**。落法三条：

1. **有位置**：存 `viewpoint`（主体、日期、可撤回），或作为 `question.kind='view'`；不与 `observation`/`measurement` 同表。
2. **有标记**：界面与导出都标"我的看法，不是医生结论"；不参与任何派生计算，不进趋势图，不进摘要的事实区。
3. **有出口**：可一键转成"想问的问题"去和医生核对——**这是它的用途：把担心变成可讨论的条目，而不是让产品替医生下判断。**

"边际"的准确含义：信息本来就存在（出院小结、化验单、记忆里），工作台只做**归拢、标出处、按时序摆好**，不新增判断。产品多做一步（判定、建议、评分）就越界。

以上"不可以"项在原型里用文案与交互同时约束（没有入口，而不只是免责声明）。
