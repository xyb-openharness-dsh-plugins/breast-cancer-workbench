- 代表：乳腺癌患者和照护者（用户要求）；主要操作者及双方冲突处理待确认。
- 希望改善的结果：减少资料整理和代办负担、便于就诊沟通（设计建议）。

- 协作：每轮一个关键决策，Agent 更新记录；未确认项保持假设。
- 已授权：检查参考项目、建立目录、需求研究、互动 SPEC 设计。当前不涉及远端发布或真实患者数据导入。
- 实际使用技能：ai-spec（UI 阶段直接写单文件 HTML 原型，未引入额外 UI 技能）。
- 独立审查：待执行，不能以自审代替。
