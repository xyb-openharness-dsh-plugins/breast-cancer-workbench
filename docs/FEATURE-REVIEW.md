## 逐项适配候选

| 功能域 | 小胰宝参考 | 卵巢癌参考增益 | 乳腺癌候选与理由 |
| --- | --- | --- | --- |
| 看板 | 病程/安排与入口 | 新确诊、资料杂乱两个任务入口 | 当下任务与阶段摘要；阶段由用户选/改，不自动判定进展 |
| 病情整理 | 原件、解析、核对、档案 | 先草稿、少量疑点、版本回源 | 保留闭环；病理按取样时间/部位/侧别组织，不把不同病灶压成一个最新值 |
| 指标检测 | 分类、记录、趋势 | 独立指标语义和可比性规则 | 独立二级模块；病理标志信息与可连续测量指标采用不同显示方式，不能都画成同一曲线 |
| 病情一图秀 | 独立页面、治疗/指标时间线 | 多轨、快照、与来源往返 | 保留独立入口；同一时间窗回顾治疗、检查和主动选入的症状，不据曲线判断复发 |
| 临床 | 临床匹配、试验收藏/询问 | 治疗历程、临床档案、检索/对照/关注/来源 | 建议采用“临床”入口，完整保留治疗与研究线索；所有数据源需要乳腺癌适配 |
| 营养 | 体重、摄入、制剂与趋势 | 少量即可保存，估计与缺失分开 | 保留营养支持主轴，按当次进食困难和专业建议提供帮助；不照搬胰腺癌特有流程 |
| 心理 | 感受、记录和资源 | 主体、代记、私密与分享合同 | 患者及照护者各自支持；身体形象、亲密关系和复发担忧作为可选话题，不默认公开 |
| 全程管理 | 安排、症状与日常管理 | 计划/实际分离、阶段可并行 | 建议增加康复与长期生活二级任务，先整理既定建议、困扰与沟通问题；不自动给康复处方 |
| 收藏与回顾 | 试验、报告与Agent结果 | 来源/版本/过时提醒 | 同源复用已保留解释、问题和回复，支持按分享范围导出 |
| Agent | 原生会话及页面摘要 | 解释、讨论选项、缺项、回存 | 集中适配原生会话；一期只做整理/回溯/生成提问，解释性建议为二期开关（D05 已降级，不阻塞） |
| 文件导出 | PDF/JPEG/HTML/MD/DOCX | 每种真实格式独立验收 | 五种列为候选，不能据参考实现直接标成本项目已完成 |

## 不能直接复制

疾病分期、病理/分子判定、试验快照、解析规则、引用知识和照护解释均需重新核验；不将CA125/HE4、胰腺癌PEI、HRD等参考默认逻辑替换标签后沿用。也不预设所有乳腺癌患者都应进行同一套检测。

全病程不等于强制依次经过复发、临终等阶段。支持照护可与治疗并行；安宁/临终和去世后家属支持是否进入首版需单独讨论，当前没有自动判定或阶段切换设计。

## 乳腺癌专属场景的落点（v0.2 新增）

用户第一条反馈是"术后康复、淋巴水肿护理这些实际话题基本没覆盖"，第二条是一图秀太浅，第三条是卡片翻转不对。前两条的根因不是能力缺，而是**参考架构的抽象层级只到"全程管理"**，癌种特有的动作没有下钻成字段与界面。v0.2 的落点：

| 场景 | 参考架构里的位置 | 乳腺癌要加的东西 | 落在哪个模块/字段 |
| --- | --- | --- | --- |
| 术后带管出院、引流量逐日减少 | 全程管理 → 安排与症状 | 引流管侧别、每日引流量（ml）、拔管条件由医生给，不由工具判定 | `CareStage=术后恢复` 的阶段话题；`DrainRecord`(date, side, volumeMl)；看板待办 |
| 患侧手臂发沉、袖套变紧、握不住东西 | 全程管理 → 康复（参考里是笼统"康复"） | 四点位双臂围（腕横纹/前臂中段/肘上10cm/腋下10cm）、患健侧差值、同一测量者与体位才可比 | 二级 `上肢与淋巴水肿`；`ArmCircumferenceSet` = 1 set + 4 `Measurement`；`arm_diff` 作为一类指标进一图秀 |
| 内分泌治疗长期副作用（关节痛、潮热、骨密度下降） | 全程管理 → 长期生活；指标检测 | 骨密度 T 值、体重/BMI 与治疗起止并列看；症状用强度轨道不画曲线 | `CareStage=内分泌治疗期`；`SymptomEntry`(ordinal)；`bmd`/`weight`/`bmi` 进指标字典 |
| 放疗皮肤反应、心脏毒性随访 | 指标检测 | LVEF 单独成一类（治疗相关监测，不等于肿瘤标志物） | `MetricDefinition.cat=心功能`；`radiotherapy` 事件带 `radiationField` |
| 复查前的沟通准备 | 收藏与回顾 / 临床 | 把"这三个月手臂差值涨了 0.6cm"这类变化直接生成提问草稿 | `#review/问题清单`，Markdown 导出 |

配套的字段与取值范围见 [BREAST-DOMAIN](BREAST-DOMAIN.md)，场景编号见 [SCENARIOS](SCENARIOS.md) 的 S8/S9/S10。**四条硬约束**（已在原型与文档同时落实）：

1. 四点位测量必须带测量者角色与体位协议，否则不合并成一个"臂围"数。
2. 患健侧差值只做展示与提示"建议和医生讨论"，不给诊断阈值结论；2cm 是**参考关注线**，不是判定标准（待专业核验）。
3. 症状 0–3 是主观强度，不能与检验值共用纵轴或画成同一条趋势线。
4. 术后阶段的"已完成/建议做"由用户从既有医嘱里整理，工具不生成康复处方。
