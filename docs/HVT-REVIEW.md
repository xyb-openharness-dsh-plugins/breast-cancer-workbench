## 0. 结论

乳腺癌的**核心专属场景是全仓最扎实的一处**：腋窝处理 + 放疗野 + 四点位臂围 + 2cm 参考线 + 方法变更断线，从场景（S8）到字段（`arm_diff`）到验收（A9/A10/A14）都能追。这与肺癌/卵巢癌"主线很全、腹部或呼吸全空"的情况不同。

问题集中在**"指标进了字典，但没有场景和验收"**这一层：LVEF、腰椎 T 值、`ai_joint`、`skin_rxn` 都在 `BREAST-DOMAIN` 里定好了量纲和呈现方式，却没有对应的患者任务、页面行为和可执行验收。开发照字典做，会得到"图上有一条线，但没人知道什么时候该看它、看到变化该说什么"。

| --- | --- | --- |
| B 阻塞 | 0 | 有场景、无落地 |
| G 缺口 | 3 | 缺关键层（BR-03 心脏、BR-04 骨健康、BR-06 生育） |

## 1. 方法与口径

- 疾病轴：本癌种在 A2 解剖（腋窝处理 + 放疗野 → 上肢）、A4 治疗组合（内分泌 5–10 年、抗 HER2、放疗）、A6 毒性（关节痛、骨丢失、心脏、皮肤）、A7 生活影响（身体形象、生育与性健康）上差异显著；A5 转移（骨）与多数实体瘤共享，不单列为癌种特有。
- 打分与五层：见技能 `references/scoring-rubric.md`、`five-layer-check.md`。
- **人工修正脚本初值 4 处**（脚本按术语命中，不认语义）：
  1. `BR-02 内分泌` 脚本给 C=1（S=1，M/F/I/A=0）。实际 `SCENARIOS.md:15` 有 S9 完整任务、`UI-DESIGN.md:21` 有页面归入、`BREAST-DOMAIN.md:97` 有 `ai_joint` 字段，人工判 S/M/F/I 各 1、A=0，**C=4**。
  2. `BR-05 放疗皮肤` 脚本给 C=1 且警告"有模块/字段但无场景"。实际 S4 已把"皮肤"列为术后/放疗后的可选困难（`SCENARIOS.md:10`），判 S=1、M/F=1、I=0、A=0，**C=3**。
  3. `BR-03 抗 HER2 心脏` 脚本给 C=0。实际 `BREAST-DOMAIN.md:65` 定义了 `lvef`（单位、折线 + 基线参考带、方法需记录），"指标检测"模块承载它，人工判 M=1、F=1，**C=2**。
  4. `BR-06 生育` 脚本给 C=0。实际 `BREAST-DOMAIN.md:29/121` 有字段级约定与"可以/不可以做"，心理支持下有"身体与亲密"页，判 M=1，**C=1**。
- `BR-07 骨转移` 脚本 0 命中：本报告**不单列**该场景。骨转移在乳腺癌常见，但"按部位记录转移、不自动诊断"是全部实体瘤共享的通用能力，按门槛 S<2 剔除；骨**健康**（AI 相关骨丢失）保留为 BR-04。

## 4. 差异评价

### 达标 BR-01 上肢与淋巴水肿

- **证据**：`SCENARIOS.md:14`（S8 触发→四点位→差值→问题）；`BREAST-DOMAIN.md:81/86`（`arm_flex`、命名约定 D15）；`SPEC.md` §3 二期页"上肢与淋巴水肿"、A9/A10/A14；`UI-DESIGN.md:109-110`（红色提示与护理要点边界）。五层齐，且**边界写得比多数项目清楚**（单次不判分期、方法变更断线、不推荐压力等级）。
- **处置**：无补丁。仅提示 2cm 与四点位方案仍属待专业核验项（U1）。

### G1 抗 HER2/蒽环的心脏监测（BR-03）

- **现象**：`lvef` 已在指标字典定义了单位、呈现方式与"方法需记录"（`BREAST-DOMAIN.md:65`）；`GAP-ANALYSIS.md:57` 把"心脏毒性"的设计答案写成"LVEF 指标序列"。但**没有任何患者场景**：什么时候该测、与哪段治疗同窗、看到下降该说什么，全空。验收 A1–A24 中无一条提到 LVEF。
- **影响**：图上有一条 LVEF 线，但用户不知道它是"化疗/靶向期间要盯的安全线"。指标存在不等于问题被回答；这正是"提到 ≠ 覆盖"的另一种形态——**字段级覆盖，任务级空白**。
- **处置**：补丁 P1。

### G2 生育与性健康（BR-06）

- **现象**：`BREAST-DOMAIN.md:29` 把"生育与性健康"列为字段维度（生育意愿、月经状态、是否需转介），`:121` 写了"提供提问清单与转介提示 / 不给能否怀孕结论"；`GAP-ANALYSIS.md:61` 明确记为"仅 FEATURE-REVIEW 一句"。心理支持有"身体与亲密"页，但**没有场景、没有字段表、没有验收**。
- **影响**：这是年轻患者最需要"有人告诉我可以问"的一类，且极易被做成沉默项。已有隐私三过滤（`DATA-FLOW-SPEC.md:164`）是好基础，但"记什么、怎么问、默认不分享"没有落到可执行条目。
- **处置**：补丁 P2。

## 5. 需求补丁

### P1 治疗相关器官毒性 → 并入 `docs/SPEC.md` §4（产品立场之后新增一节）

> **LVEF 与骨密度只做"与治疗同窗的记录"，不做毒性判定。** 正在或曾经使用蒽环类、抗 HER2 的患者，可记录 LVEF 数值、检查日期、测量方法（echo/MUGA/其他原文）与机构；正在使用 AI 的患者，可记录腰椎 DXA 的 T 值、检查日期与机构。两项均与治疗事件同轴显示，页面常显"这是检查结果记录，是否继续或调整治疗由治疗团队决定"。
>
> **不做什么。** 不设"下降多少算毒性"的阈值提示，不生成心脏毒性或骨质疏松的判断，不给钙/维生素 D 剂量，不因单次变化建议复查频率。

**判据**：`SPEC` §7 新增验收（A25/A26）；`BREAST-DOMAIN` 的两条指标定义补"与哪类治疗同窗"；页面能被指认出"这条线为什么在这里"。

### P2 生育与性健康 → 并入 `docs/SPEC.md` §3（心理支持二级页）与 §7

> **生育与性健康是可选话题，不是必填表。** 提供"可以问的问题"清单（化疗/内分泌对生育的影响、是否需要转介、月经变化要不要说、避孕与性生活的沟通），可只记一句"我想问这个"；是否记录生育意愿、月经状态、是否已转介均为自愿。
>
> **边界。** 不给"能否怀孕"的结论、不按年龄推断、不推荐具体生殖中心、不评价治疗方案；默认私密，不进一图秀、摘要、导出与 Agent 预览（沿用 `DATA-FLOW-SPEC` 三处过滤）。

**判据**：`SPEC` §7 新增验收（A27）；心理支持二级页有独立入口；A12 的私密边界覆盖新增字段。

### P3 内分泌副作用与放疗皮肤 → 并入 `docs/SPEC.md` §7

> 症状强度按 0–3 自评记录，**用强度轨道呈现，不画成趋势曲线**；部位、与用药/放疗时间的对照可见；不出现"这是药引起的"这类归因句。放疗皮肤反应记录部位（对应放疗野）、外观描述原文、是否已联系团队；分级只引用院方原文，不自拟。

**判据**：新增验收（A28/A29）。

### P4 术式与身体形象 → 并入 `docs/SPEC.md` §7

> 术式（保乳/全乳切除/改良根治/重建，含即刻或延期）是独立字段，不与其他治疗混写；身体形象话题由用户主动打开，默认不出现在摘要与导出。

**判据**：新增验收（A30）。

### P5 术后引流 → 并入 `docs/SPEC.md` §7

> 引流量按日记录，同日多次不合并、量缺失保持空缺；拔管后记录归档但可回看。

**判据**：新增验收（A31）。

### P6 发布可见性 → 并入 `docs/SPEC.md` §4 与 §7

> 版本号单一来源为仓库根 `VERSION`；HTML 原型首屏（顶栏或页脚）可见，装机后的工作台首屏同样可见；版本、构建日期、来源、渠道四项可在"关于"读到；未发布时明写未发布。

**判据**：`VERSIONING` 已定规则，A23 覆盖 HTML 侧；新增 A32 覆盖装机侧（P2）。
