## 与 v0.1 的差异

- 删除：一图秀的"上下展开"指标卡、单序列假曲线、治疗文字 chip 附底。
- 新增：治疗条、症状轨道、16 指标字典、术后恢复、上肢与淋巴水肿、长期生活话题、hash 直达。
- 保留：八模块导航、资料闭环、私密边界、计划/实际分离、问题清单导出。

## 仍缺

- 一期 Markdown 之外的真实导出格式（PDF/JPEG/HTML/DOCX）。
- 真实解析、真实试验数据、真实 Agent 会话。
- 更正传播（A14）在原型只做了测量新增，未做"更正旧记录并标注过期"的完整演示。
- 键盘全链路与屏幕阅读器走查。
